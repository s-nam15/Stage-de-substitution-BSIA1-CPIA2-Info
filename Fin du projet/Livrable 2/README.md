##### 1\. Bibliothèque à installer



Installation de l'API officielle Niryo (pyniryo -> la **passerelle** entre le programme python et le robot) :



* pip install pyniryo







##### 2\. Connexion PC - robot



Tout d'abord, allumez le robot. Une fois la LED passe du rouge au bleu, connectez votre PC au robot en Wi-Fi s'appelle **« NiryoRobot e8-751-5ae »** en saisissant le mot de passe : niryorobot
